# 深空当铺鉴定助手

《深空当铺》Windows 桌面鉴定工具，支持仿生机械手、等离子燃料匣和肋明治。

## 使用

1. 从 [Releases](https://github.com/Sybc-1/Probably-Stolen-Authentication-Assistant/releases) 下载 Windows x64 压缩包。
2. 完整解压后运行 `PawnAppraiser.exe`，保持 `items` 文件夹与程序在同一目录。
3. 选择物品并按实物勾选检查结果，点击价格或“复制数字”复制鉴定价格。

程序为便携式版本，无需安装 .NET 运行时。

## 功能

- 根据所选材料、品相和其他特征实时计算价格。
- 支持三种物品，分别保留当前选择。
- 已有检查足以确定固定价格时，可立即复制；修改条件后实时重新计算。
- 提供悬浮窗口、置顶、透明度、托盘和可配置快捷键。

默认小键盘 `*` 展开或收起，小键盘 `/` 显示或隐藏。关闭窗口会隐藏到托盘；彻底退出请使用托盘菜单。

鉴定规则保存在 `items` 的 JSON 文件中，由玩家识别实物并手动选择。程序不读取游戏内存、不修改游戏，也不自动识别画面。
